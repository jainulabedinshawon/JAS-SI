JAS-SI Hybrid Licensing Strategy v1.0

Project: JAS-SI (JAS Intelligence)
Licensing Model: Hybrid / Open Core
Strategy Status: Proposed — Pending Implementation

1. Core Architecture — Proprietary

The following components are designated for proprietary commercial licensing:

- Core authorization engine
- Independent verification engine
- Security and governance implementation
- Enterprise verification modules
- Commercial integrations

2. Community Edition — Open Source

The following components are candidates for Apache License 2.0:

- Public SDKs and client libraries
- API integration examples
- Developer documentation
- Community integration tools
- Public development utilities

These components must be separated from proprietary implementation before publication.

3. Research and Publications

Research papers, benchmark specifications, and methodology documents will have separately defined publication and licensing terms.

4. Commercial Licensing

Enterprise customers may receive commercial licenses for proprietary JAS-SI components under separately defined terms.

5. Licensing Safeguards

- No proprietary source code will be relicensed under Apache 2.0 without an explicit decision.
- Third-party dependencies must retain their applicable licenses.
- Contributor ownership and licensing permissions must be reviewed.
- Public visibility does not imply permission to reuse proprietary source code.

6. Release Policy

The licensing structure must be reviewed before publishing JAS-SI API v0.1.0 as an open-source release.
